# منصة أثر التدريبية — البرنامج التأسيسي في الذكاء الاصطناعي

منصة البرامج التدريبية لمركز أثر. أول برنامج عليها: **البرنامج التأسيسي في الذكاء الاصطناعي (AI 101)** — أربعة أسابيع، حضور مباشر، مهام أدائية، مشروع ختامي، وشهادة.

المنصة **عربية بالكامل، اتجاهها من اليمين إلى اليسار**، وتوقيت عرضها `Asia/Riyadh`، وتخزينها `UTC`.

> **قبل أي سطر كود:** اقرأ `CONSTITUTION.md` كاملًا، ثم `PROJECT-CONTRACT.md`. ليسا توصيات.

## التشغيل محليًا

### المتطلبات

- PHP **8.2** أو **8.3** مع الامتدادات: `pdo_mysql` · `mbstring` · `openssl` · `json` · `fileinfo` · `gd` · `zip`
- Composer 2
- Node.js 20+ و npm
- MySQL 8 أو MariaDB 10.6+ محليًا

### الخطوات

```sh
# 1. التبعيات
composer install
npm install

# 2. البيئة
cp .env.example .env
php artisan key:generate

# 3. اضبط في .env بيانات قاعدة البيانات المحلية، ثم:
php artisan migrate --seed

# 4. البناء والتشغيل — في طرفيتين
npm run dev
php artisan serve
```

المنصة على `http://localhost:8000`.

### الطابور محليًا

**لا يوجد عامل دائم في الإنتاج** (المادة 10)، فحاكِ الإنتاج لا خلافه:

```sh
php artisan queue:work --stop-when-empty
php artisan schedule:run
```

`QUEUE_CONNECTION=database` و`CACHE_STORE=database` و`SESSION_DRIVER=database` محليًا أيضًا. **لا تستخدم `sync` ولا `redis`** — ما لا يعمل على الإنتاج لا يُختبَر محليًا.

### البيانات

`php artisan migrate --seed` يبني **دفعة كاملة قابلة للاختبار يدويًا** (المادة 29): البرنامج، دفعة واحدة، أربعة أسابيع، عشر خطوات رحلة، جلسات، مهام، حضور، تسليمات، شهادة.

**في الإنتاج لا يُشغَّل `DatabaseSeeder` أبدًا** — بيانات وهمية فقط. البذر الإنتاجي الوحيد المسموح هو `ProgramSeeder`. راجع `deploy/README.md` §7.

## البوابات — تُشغَّل قبل كل دمج

**فشل أي بوابة يمنع الدمج** (الدستور، المادة 26).

```sh
composer run gates      # G1 … G12 بالترتيب
```

أو واحدة واحدة:

| # | البوابة | الأمر | المعيار |
|---|---|---|---|
| G1 | التنسيق | `composer run g1` | صفر انحراف عن Pint |
| G2 | التحليل الساكن | `composer run g2` | Larastan مستوى 8 · صفر خطأ |
| G3 | القائمة السوداء | `php artisan gate:forbidden` | صفر مطابقة (المادة 13) |
| G4 | حصر الوقت | `php artisan gate:clock` | صفر `now()` خارج `Clock` |
| G5 | حصر النصوص | `php artisan gate:i18n` | صفر نص عربي خارج `lang/` |
| G6 | حصر التصميم | `php artisan gate:tokens` | صفر لون مباشر · **صفر أصفر أو ذهبي** |
| G7 | الاختبارات | `composer run g7` | كلها تمرّ |
| G8 | تغطية المنطق الحرج | `composer run g8` | 100% على `app/Services` |
| G9 | التفويض | `composer run g9` | لكل مسار محمي اختبار 403 |
| G10 | قواعد العمل | `php artisan gate:br` | لكل `BR-01..36` اختبار واحد على الأقل |
| G11 | الترحيلات | `composer run g11` | تعمل في الاتجاهين |

بعد البوابات، **مراجعة بعقل منفصل** (المادة 27): `athar-logic-verifier` للوقت والحضور والدرجات والشهادات والرحلة · `athar-security-reviewer` للمصادقة والصلاحيات والرفع والمعاينة والصفحات العامة · `athar-ui-reviewer` لكل مكوّن وصفحة.

## قواعد تُنسى كثيرًا

- **الوقت:** `Clock::now()` وحده. `now()` و`Carbon::now()` و`new DateTime` و`time()` و`date()` **ممنوعة** خارج `app/Services/Time/Clock.php`. البوابة G4 تفرضها.
- **النصوص:** لا حرف عربي واحد داخل `.php` أو `.blade.php`. كل نص عبر `__('file.key')` من `lang/ar/`.
- **التصميم:** لا لون ولا مسافة ولا خط مباشرًا. كل شيء من `resources/css/tokens.css`.
- **ممنوع الأصفر والذهبي بكل درجاتهما** — في كل مكان، بلا استثناء.
- **RTL:** خصائص منطقية فقط. أشرطة التقدم تمتلئ **من اليمين**. القائمة الجانبية على **اليمين**.
- **الحروف العربية متصلة:** يُمنع تقسيم نص عربي إلى حروف في عناصر منفصلة. التقسيم على مستوى **الكلمة** فقط.
- **الأرقام لاتينية** (1234) · التواريخ «الأحد 12 أكتوبر 2026» · الأوقات 12 ساعة بـ صباحًا/مساءً.
- **كل شاشة أربع حالات:** عادي · تحميل (skeleton بشكل المحتوى) · فارغ (بنص خاص بها) · خطأ.
- **الخادم هو الحَكَم:** إخفاء زر ليس حماية، وتعطيل حقل ليس تحققًا، و`@can` في Blade ليس تفويضًا.
- **`env()` ممنوع خارج `config/`** — لأن `config:cache` يُبطلها.
- **لا حذف فعلي** لمستخدم أو حضور أو تقييم أو شهادة.

القائمة الكاملة الملزمة في `CONSTITUTION.md` المادة 13.
